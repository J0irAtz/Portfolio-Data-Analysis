# 📊 Portafolio de Análisis de Datos

¡Hola! Bienvenido a mi repositorio principal de proyectos de análisis de datos. 

Aquí documento los proyectos que desarrollé durante el bootcamp de **TripleTen**, aplicando técnicas de limpieza de datos, análisis exploratorio (EDA), visualización y modelado predictivo para resolver problemas de negocio reales.

## 📁 Proyectos Incluidos

### 1. [Análisis de Retención y Predicción de Churn](./Análisis%20de%20Retención%20y%20Predicción%20de%20Churn.ipynb)
* **Objetivo:** Identificar los factores clave que llevan al abandono de clientes (churn) en un servicio y construir un modelo predictivo para la retención.
* **Habilidades aplicadas:** Limpieza de datos, Machine Learning (Clasificación), cálculo de métricas de retención.

### 2. [Optimización de Gastos de Marketing](./Optimización%20de%20Gastos%20de%20Marketing.ipynb)
* **Objetivo:** Analizar el embudo de ventas y el retorno de inversión (ROI) de distintas campañas publicitarias para reasignar el presupuesto de marketing de manera eficiente.
* **Habilidades aplicadas:** Análisis de cohortes, cálculo de LTV (Life Time Value) y CAC (Costo de Adquisición de Clientes), visualización de datos.

### 3. [Análisis de Competencia y Clima](./Análisis%20de%20Competencia%20y%20Clima.ipynb)
* **Objetivo:** Investigar el impacto de factores externos (como el clima) y la dinámica de la competencia en el volumen de operaciones de una empresa (ej. viajes o ventas).
* **Habilidades aplicadas:** Pruebas de hipótesis estadísticas (A/B testing o T-tests), análisis de correlación, extracción de datos estructurados.
